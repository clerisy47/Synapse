# Native foundation decisions

Implementation was authorized on 2026-10-18 by the request to complete PLAN. The current workspace contains `synapse-core` (pure values/ports), `synapse-adapters` (filesystem, OS, provider and MCP boundaries), and `synapse-terminal` (terminal library plus composition-only binary). The executable is `synapse`; crates are private. Edition 2024, toolchain and MSRV are pinned to Rust 1.85.1; Cargo.lock is application-owned. Dependency features, native build scripts and license adoption are recorded in [dependency review](rust-dependencies.md).

The terminal uses standard argument parsing and line-oriented I/O, safe OS readiness polling, Unicode cell widths and an atomic Ctrl-C cancellation signal. Both input and output must be terminals for review/Apply. There is no full-screen or raw terminal mode. Tests use real POSIX PTYs, resize them, and check terminal attributes. Synchronous model facades share one serialized queue in the process and a local-runtime lease across processes. HTTP requests use bounded deadlines; cancellation suppresses late results and preserves the active slot until transport completion. MCP alone uses a request-owned Tokio runtime behind its explicit listener boundary.

The qualified target is macOS 26.6.2/aarch64. Linux GNU x86_64 CI is defined but has not run in this local session; Linux and Intel macOS remain experimental, Windows unsupported. See [native installation](native-install.md) for the exact support/build/runtime matrix and development archive limits.

Private external state uses macOS `$HOME/Library/Application Support/Synapse`, or Linux `$XDG_STATE_HOME/synapse` (absolute only), falling back to `$HOME/.local/state/synapse`. A SHA-256 canonical workspace identity namespaces state. Owner-only no-follow state handling rejects workspace overlap and never imports legacy state. Typed files hold captures, bounded recovery, grant digests and receipt ledgers. Reviewed note replacement and scoped inbox append remain separate authorities from StateStore.

Available operations include help/version, offline/provider doctor, interactive chat, deterministic search, one-shot ask/JSON, reviewed setup/metadata/research, capture, recovery/revert, history clearing and explicitly provisioned foreground MCP. `--help` lists arguments. Fixed content-free error codes cover invalid inputs, provider failures, conflicts and recovery requirements. Control files are not required for search/chat.

Run the pinned compiler/format/Clippy/tests, `scripts/check-rust-boundaries.py`, and native release build. The source guard pins crate dependencies and reviewed I/O/network/write/schema capabilities; it is a conservative architecture guard, not an OS sandbox. Native CI never invokes npm. Real PTY, live Bonsai, native-client and package checks are separately recorded in [qualification evidence](evidence/native-qualification-2026-10-19.md).

The initial dependency-free five-test foundation is historical evidence only. Current behavior has its own tests. Interrupted TypeScript reader/npm modifications remain untouched; historical TypeScript source/tests are not in the Rust build or native archive. Generated legacy output was removed through a conservative tool after implementation.
