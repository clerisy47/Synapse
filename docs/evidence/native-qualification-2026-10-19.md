Failures and corrections retained:

1. Local llama.cpp required its native JSON schema envelope rather than the remote OpenAI-style envelope.
2. An unset PTY width wrapped a test's folder label; the harness now sets a real width and separately tests narrow rendering.
3. A live research response combined inconsistent status/provenance. Discriminated draft/insufficient schema branches corrected the synthetic case; malformed output was refused without notes changing.
4. The first broad quality run was 11/12, with a refused malicious-note response and no privacy leak. Restricting the local selection schema to supplied IDs and coherent answered/insufficient branches yielded 12/12. Both reports remain committed; no test was removed.
5. Concurrent creation of the shared lock file exposed an ENOENT race on this host. Exclusive create followed by a separate existing-file open passed the competing-process regression.
6. Denied unread HTTP bodies can cause TCP reset; this is counted as refusal. Rate-limit responses now consume bounded authenticated raw bodies before returning 429 so compliant clients receive the status.
7. Some crate archives omitted license texts. The package includes upstream exact-commit MIT copies for rmcp/macros and the selected Apache-2.0 license for unicode-casefold, with provenance recorded in docs/licenses/README.md.
8. A noncanonical temporary HOME under /var was refused by the no-symlink state policy. Canonical /private/var temporary HOME passed clean installation.

9. A final release run intermittently failed a native-client retry after earlier passes. The stateless wrapper waited for SSE channel EOF after an already complete response. It now owns one runtime per request, consumes one bounded complete envelope, bounds the full response read and cancels residual SDK tasks. Two release native-client/security/concurrent-write runs passed after this lifecycle change. The earlier failure remains recorded; the result is a finite regression check, not a universal transport proof.
