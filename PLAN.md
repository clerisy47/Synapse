## Release gates

All Rust implementation tasks must meet their acceptance criteria, required checks and standalone build/install smoke. Quality and real-terminal/client gates stay open until evidenced. See [release validation](docs/release-validation.md). A working legacy host or TypeScript build does not close any Rust gate. RUST-T01 establishes only the native foundation; publication and release qualification remain open.
